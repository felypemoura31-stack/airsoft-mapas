# Airsoft Battlefield

Mapas em PDF com GPS, offline, para jogos de airsoft.

[![Baixar o app Airsoft Battlefield para Android](baixar.svg)](https://airsoft-loja.felypemoura31.workers.dev/baixar)

### Como instalar

1. No celular Android, toque no botão laranja. O download do app começa.
2. Abra o arquivo baixado e toque em **Instalar**.
3. Se o celular pedir, permita instalar apps vindos do navegador.

Depois disso, o app se atualiza sozinho quando sair uma versão nova.

Se o botão não funcionar, baixe o arquivo `.apk` na página [Releases › app](https://github.com/felypemoura31-stack/airsoft-mapas/releases/tag/app).
